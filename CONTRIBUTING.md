# Contributing

Issues and pull requests are welcome at https://github.com/nodestep-ai/text-to-sql-demo.

Set up as in the README's [Setup](README.md#setup), then run the checks under [Development](README.md#development) before you open a pull request. CI runs the same ones.

Dependencies are pinned to exact versions. Install npm packages with `--ignore-scripts`.

Every user-visible change gets a line under `## [Unreleased]` at the top of `CHANGELOG.md` (add the heading if it is not there), in the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) section that fits: `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed` or `Security`.

The guide is the README; `docs/` holds the API and security pages.
